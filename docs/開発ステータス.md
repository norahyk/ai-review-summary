# 日用品価格比較アプリ 開発ステータス

本ドキュメントは、日用品価格比較アプリの現在の開発状況および今後のタスク（Next Task）をまとめたものです。

---

## 現在の開発状況 (フェーズ3 進行中)

現在、Supabaseを用いたデータ基盤の構築（フェーズ3）への移行、およびUIコンポーネント・機能の改善が進行しています。

### 1. データ基盤・バックエンド (Supabase)
- **データベース設計**: LocalStorageからの移行として、Supabase上に宣言的SQLスキーマ（`items`, `brands`, `stores`, `purchase_records`, `households`, `profiles`, `user_settings`）を構築。
- **認証機能**: Next.js Auth (`@supabase/ssr`) を用いたログイン・サインアップ機能、およびHousehold（世帯）共有モデルの基盤を実装。
- **マスターデータ管理**: `app/master/page.tsx` において、カテゴリ（アイテム）、ブランド、店舗の新規登録および管理ができる専用画面を実装。

### 2. SPA構成とモダンUI (Next.js App Router)
- **ルーティング改善**: `app/(main)` 配下に主要ページを分割・整理し（ルート画面、`history`、`settings`、アイテム詳細など）、保守性と画面遷移設計を最適化。
- **UIコンポーネントの改善**: アクセシビリティとカスタマイズ性向上のため、一部のUIコンポーネント（Selectなど）を Base UI へ移行。asChildの制限回避や表示崩れの修正を実施。
- **デザイン**: Tailwind CSSと `lucide-react` を用い、スマートなUIを提供。動的カテゴリアイコン（DynamicIcon）の表示機能も改善。

### 3. クイック判定・比較機能
- **カテゴリ選択 UI**: アイテムを「キッチン」「お風呂」「ランドリー」等の場所別にグループ化し、直感的に選択できるダッシュボードを実装。
- **価格比較アルゴリズムとUI**: 内容量と税抜・税込価格から単価（100mlあたり等）を算出し、同カテゴリ内の他ブランドとの相場比較や、過去の購入履歴との最安値比較を行うロジックを精緻化。比較結果UIの視認性も向上。
- **価格推移・販売店表示**: 商品ごとに過去の価格推移や購入した店舗の情報を分かりやすく提示するUIの提案と実装。

### 4. 検索機能
- ヘッダーからの絞り込み検索により、目的のアイテム・ブランドの価格相場へ素早くアクセス可能。

### 5. PWA機能の統合
- 「設定」タブ内に機能を集約し、アプリらしいシームレスな体験を維持。

## Next Task (今後の課題)

Supabase統合およびマスターデータ管理の基盤が整ったため、今後はより高度な分析・利便性向上へ移行します。

### 1. 価格推移の高度な可視化（グラフ化）
- 要求仕様書の「今後の検討事項」にある、単一商品の価格変動トレンドを視覚的に把握できる折れ線グラフ等の本格的な表示機能の実装。

### 2. データ連携の網羅的なテストとバグフィックス
- Supabaseへの完全な置き換えに伴う、エッジケース（未ログイン時の挙動、Row Level Security (RLS)の厳密なテスト、ネットワークエラー時など）の対応。
