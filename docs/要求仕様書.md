# 日用品価格比較アプリ 要求仕様書

## 1. 目的

店舗での買い物中に、目の前の日用品が「買い時」かどうかを、直近の購入価格や同じカテゴリ（アイテム）内の他商品と比較することで、即座に判断できるWebアプリケーションを開発する。物価変動に対応するため、過去の最安値よりも直近の相場感覚を重視する。

## 2. ターゲットユーザー

- 提案者本人および配偶者（ブランドにこだわらず、その時最もお得な商品を選択したいユーザー）
    

## 3. 前提条件・制約事項

- **プラットフォーム:** Webブラウザで動作するアプリケーション（スマートフォンからの利用をメインに想定）
    
- **データ入力:** ユーザーによる手動入力
    
- **価格基準:** すべて「税抜価格」で統一して記録・比較する
    
- **データ管理:** ユーザー間（夫婦間）でデータ（商品情報、価格情報など）を共有・同期できること
    

## 4. 機能要件

### 4.1. 商品・アイテム管理機能

- **アイテム（カテゴリ）管理:** 「食器洗剤」「シャンプー」「トイレットペーパー」などの大分類を登録・編集・削除できる。
    
- **商品情報の登録・編集・削除:**
    
    - 必須項目: アイテム、ブランド/シリーズ名（例: 「キュキュット クリア除菌」「JOY PRO洗浄」）、基準単位（例: 「100ml」「100g」「1ロール」など）
        
- **入力補助:** 過去に登録したアイテムやブランド/シリーズ名を、サジェストやドロップダウンリストから選択できるようにする。
    
- **アイテムと連動したブランドの絞り込み:** アイテム（例：シャンプー）を選択した際、他のアイテムに紐づくブランド（例：キュキュット）がサジェスト表示されないように制御する。
    

### 4.2. 価格記録機能

- **購入情報の登録:**
    
    - 必須項目: 商品、税抜価格、内容量（例: 700ml）、購入店舗（例: コスモス、エバグリーン、ツルハ）、購入日
        
    - **デフォルト値の活用:** 入力負担軽減のため、購入日は「当日」、購入店舗は「直近で利用した店舗」を初期設定値として表示する。
        
    - **税込価格からの換算アシスト:** 税込表示しかない店舗に対応するため、入力画面に「税込から換算（8%・10%）」機能を設ける。ユーザーが税込価格を入力して税率を選ぶと、自動で税抜価格に換算され入力欄に反映される。
        
- **単価の自動計算ルール:**
    
    - ユーザーにはパッケージ表記通りの数値（例: 内容量「340」）を入力させる。
        
    - 計算式: `単価 = 税抜価格 / (入力内容量 / 基準単位の数値)` に基づき、基準単位あたりの単価を自動計算し記録する。（例: 340mlの詰替用を基準単位100mlで計算する場合、`税抜価格 / (340 / 100)`）
        
- **店舗情報の管理:** 購入店舗のリストを登録・編集・削除できる（入力時のサジェストに利用）。
    

### 4.3. 買い時判定（価格比較）機能

- **クイック判定（商品単位）:**
    
    - 目の前にある商品の「税抜価格」と「内容量」を入力すると、基準単位あたりの単価を自動計算する。
        
    - **マルチ比較表示とカスタマイズ:** 計算された単価を過去のデータと比較し、安い/高いを直感的に表示する。
        
        - **メイン表示:** ユーザー設定で指定した基準（デフォルトは「最新の購入単価」）と比較し、判定結果を大きく表示する。
            
        - **サブ表示:** 「直近3件の平均単価」や「過去1年の最安値」も同時に表示するが、判定の邪魔にならないよう強調しすぎないデザインとする。
            
        - **設定変更:** どの指標（最新、平均、最安値）をメインの強調表示にするかは、ユーザー設定画面からいつでも変更可能とする。
            
    - **シームレスな記録遷移:** 判定のために入力した「税抜価格」と「内容量」のデータを維持したまま、ワンタップでそのまま「購入情報の登録」画面へ引き継ぎ・保存できる導線とし、二度手間を防ぐ。
        
- **アイテム内比較（カテゴリ単位）★重要機能★:**
    
    - クイック判定画面、または検索結果画面において、入力した商品だけでなく、**同じアイテム（例：シャンプー全般）に属する他の商品の直近単価も一覧表示**する。
        
    - これにより、「いつも買っているAより、今日はBの方が安い」といった、ブランドを跨いだ最安値の判断を可能にする。
        
- **詳細履歴表示:**
    
    - 各商品の過去の価格履歴（購入日、店舗、内容量、税抜価格、単価）を時系列で一覧表示する（直近の価格変動を把握するため）。
        

### 4.4. 検索機能

- アイテム名、ブランド/シリーズ名、店舗名などから素早く検索できる。
    
- 特に「アイテム名（例：シャンプー）」での検索を容易にし、現在登録されているシャンプーの直近単価一覧をすばやく表示できるようにする。
    

## 5. 非機能要件

- **ユーザビリティ:** スマートフォンを片手で持ちながら、短い時間で入力・確認ができるシンプルなUI。入力項目は極力減らし、タップ操作を主体とする。判定から記録へのシームレスな画面遷移を実現する。
    
- **レスポンス:** 買い物中の利用を想定し、検索や判定結果の表示はスムーズに行われること。
    
- **セキュリティ・プライバシー:** 夫婦間でのみ利用するため、強固な認証システムは必須ではないが、第三者にデータが閲覧されない最低限のアクセス制御（簡単なログイン・パスワードなど）を設ける。
